# Scaffold — только Telly

В Scaffold удалены старый edge-mode, Jump Assist и переключатель Telly Mode.
Включение Scaffold теперь сразу включает Telly. Отдельный Coach и recorder сохранены
для ручных тренировок/записей; для автоматического Scaffold Coach нужно выключить.

## Запуск

Одиночный мир, `/tick rate 20`, клиентский timer 1x, без creative flight и других
gameplay-модулей. На полной платформе повернуться вдоль X и удерживать W или S.
Scaffold разгоняется, запрашивает прыжок у края, доводит видимую камеру к доступной
грани, ставит блоки на фиксированной высоте в одном ряду и возвращает взгляд вперёд.
RMB/Alt не нужны. При Auto Jump OFF прыгать Space вручную.

При открытии GUI/потере фокуса/отпускании W/S цикл сбрасывается. После возвращения
на полную платформу с W или S можно начать снова **без выключения/включения** модуля.
Причины паузы выводятся в чат при включённом Diagnostics. Если конфликтует другой
модуль, сообщение содержит его имя. После падения новый старт только с земли.
Остановка ввода не обнуляет инерцию: проверять над безопасной площадкой!

## Собственные настройки

| Настройка | Default | Назначение |
| --- | --- | --- |
| Telly Auto Jump | ON | Автоматический прыжок перед краем; OFF — ручной Space |
| Telly Sprint | ON | Разгон/sprint на отрыве при W; задний ход S не получает невозможный vanilla backward sprint |
| Telly Auto Switch | ON | Выбрать полный строительный блок из hotbar для клика, вернуть исходный слот |
| Telly Swing | ON | Взмах при принятом взаимодействии |
| Telly Diagnostics | ON | Сообщения о причинах паузы/отказа |
| Telly Jump Distance | 0.30 | Проверка отсутствия полного блока впереди, 0.10–0.80 блока |
| Telly Blocks | 3 | Верхняя граница уникальных блоков за прыжок, 1–4, не гарантия |
| Telly Start Tick | 1 | Первый разрешённый воздушный тик, 0–8 |
| Telly CPS | 15 | Предел wall-clock попыток 1–15 CPS; небезопасные лучи пропускаются, burst после лага нет |
| Cam Lock | ON | ON: камера следует голове Scaffold; OFF: свободный обзор мышью |
| Telly Return To View | ON | Вернуть взгляд, сохранённый перед прыжком; OFF: направление подхода по X |
| Telly Return Pitch | 20 | Pitch возврата при Return To View OFF, −60…80° |
| Telly Turn Speed | 180 | Скорость головы за 50 ms, 15–180°, применяется каждый кадр с учётом dt |
| Telly Return Speed | 180 | Скорость возврата головы за 50 ms, 15–180° |
| Telly Smoothing | 1 | 0.2–1, меньше — мягче и медленнее |
| Telly Reach | 4.5 | 2–4.5 блока, не выше native interaction range |
| Telly Aim Samples | 5 | 3–7 точек по оси грани |

Значения хранятся обычным ConfigManager. Старые параметры профилей не отображаются.
`.scafftrain start/stop/report/apply/undo` сохранены: apply переносит только скорости
в Telly Turn Speed и Telly Return Speed (с показом в report и ограничением диапазона),
но не sneak/release и не политику прыжков. Приоритет: Jump Turn Speed; иначе минимум
ground yaw/pitch. Assisted остаётся неприменимым. Undo возвращает предыдущие значения,
если после apply их не меняли вручную.

## Исправленные проблемы прежнего прототипа

- GUI, пустой слот и отпускание W больше не создают перманентный HALT.
- Удалён лишний переключатель Telly Mode, который по умолчанию оставлял старый Scaffold.
- Смещения 4/7/10 из замедленной записи больше не блокируют ранний допустимый клик.
  Настраиваются Start Tick и CPS; данные описывают движение, а не командуют им.
- После локального появления блока следующий target может обрабатываться в этом же
  callback, без отдельного пустого WAIT-тика.
- Цель подхода пересчитывается от текущей опоры: длинная платформа не оставляет старую
  далёкую цель. Прыжок по умолчанию начинается ближе к краю (0.30 вместо 0.85).
- Наведение/установка выполняются из renderFrame, независимо от 20 TPS input-цикла.
  После поворота в том же кадре выполняется новый raycast и при допустимом попадании
  native useItemOn; пакет передаёт фактическую позицию и ориентацию головы.
- W и S определяют противоположные направления движения по X. Мировое движение
  сохраняется при автоматическом развороте головы: при W голова смотрит назад к
  опоре, при S — вперёд к опоре. Скорость/позиция напрямую не подменяются.
- На старте запоминаются rowY и rowZ. Ни прыжок, ни камера не меняют их. Разрешены
  только EAST/WEST-грани и destination с теми же Y/Z; UP/DOWN и боковые ряды отвергаются.
- Приоритет — центр боковой грани. Если центр закрыт, поиск внутри центральной
  области 0.25–0.75; фактическое попадание вне области 0.2–0.8 не кликается.
- Возврат начинается после лимита блоков либо приземления. В Return To View сохраняется
  yaw/pitch перед прыжком; при OFF используется подход по X, учитывая W/S.
- Cam Lock OFF: mouse/camera hooks отделяют обзор от фактической ориентации игрока.
  Голова и native raycast смотрят на опору, камера свободно управляется мышью.
  При выключении/паузе восстанавливается свободный взгляд только текущему игроку;
  при смене мира старые углы в нового игрока не записываются.
- Null/world/player/focus/finite guards и очистка цикла при отключении сохранены.

## Данные и ограничения

`tools/analyze_telly_episodes.py` нашёл в четырёх JSONL 27 кандидатов с 3+ разными
блоками на одной высоте, в прямом непрерывном ряду. Это локальная prediction, не
server acknowledgement и не обученная нейросеть. Отчёт:
`docs/telly-episode-analysis.json`. Статистика 4/7/10 тиков остаётся описательной.
Настройки контроллера — инженерный baseline, не результат автоматического обучения.

Каждый клик требует свежего raycast, допустимой цели, полного опорного блока и
подходящего BlockItem. Нет установки через стены/вне reach. После поворота
useItemOn получает новый raycast, а не цель от старого положения камеры. Количество блоков
проверяется по локальному появлению full support, не по числу кликов.

Не гарантируются три блока в каждом прыжке и защита от падения. Только +X/−X с фиксированными Y/Z; нет tower, диагоналей и поддержки multiplayer. В среде
агента нет Java/Javac: компиляция и игровой smoke test не выполнены. Синтаксическая
проверка не подтверждает API и физику Minecraft.

Проверки перед длинным мостом: +X/−X с W и S; Cam Lock ON/OFF, мышь и F5; открытие/закрытие GUI; отпускание
W/S и повторный старт; пустой слот с блоками в другом hotbar-слоте и восстановление
исходного выбора; отсутствие блоков; Coach/Timer/TPS 3; ручной Space с Auto Jump OFF;
посадка и повторный цикл; смена мира/respawn; прыжки не меняют Y/Z ряда.
15 CPS — максимум попыток, а не гарантированные 15 блоков/с: FPS, геометрия и
native-правила могут уменьшать частоту. После обновления старые сохранённые скорости
могут остаться 90: выставить Turn/Return Speed = 180 вручную для быстрых разворотов. Тестировать только над площадкой.

Источники: собственные JSONL и текущие Input/raycast/useItemOn hooks проекта.
