# Scaffold — Eagle

`ScaffoldModule` в SkyCore оставлен только в режиме `Eagle`.

## Настройки

Модуль содержит одну настройку:

| Настройка | Значение |
| --- | --- |
| `Mode` | `Eagle` |

`Mode` сохранён как `ModeSetting`, но список режимов содержит только `Eagle`.
Другие режимы и их настройки удалены из модуля.

## Поведение

На каждом `PlayerTickEndEvent` модуль проверяет блок непосредственно под игроком.
Если это воздух, `options.keyShift` удерживается включённым, чтобы игрок не сошёл
с края. Когда под игроком снова находится блок, удержание Shift снимается.

При отключении модуля Shift принудительно отпускается, если его удерживал
`ScaffoldModule`. Модуль не меняет выбранный слот, ротацию или серверные пакеты.
