# Scaffold — Eagle и AutoPlace

`ScaffoldModule` в SkyCore работает только в режиме `Eagle`. Режимы `NCP`,
`NCPStrict` и `CatLean` не возвращались.

## Настройки

| Настройка | Значение по умолчанию | Описание |
| --- | --- | --- |
| `Mode` | `Eagle` | Единственный режим модуля |
| `AutoPlace` | `false` | Автоматически устанавливать блок моста под игроком |
| `CPS` | `10` | Максимум автоматических установок в секунду, диапазон `1–20`; видна только при `AutoPlace=true` |
| `AutoSwitch` | `Silent` | Способ выбора ячейки со строительным блоком; видна только при `AutoPlace=true` |
| `Rotate` | `Normal` | Способ ротации к грани блока; видна только при `AutoPlace=true` |
| `ClientLock` | `true` | Показывать управляемую ротацию на экране; видна при `AutoPlace=true` и `Rotate` не равен `None` |
| `LockY` | `false` | Строить только по `X`/`Z` на зафиксированной высоте моста, без подъёма по `Y` в прыжке; видна при `AutoPlace=true` |
| `Diagonal` | `false` | Разрешить строительство по диагонали (`XZ`/`ZX`); видна при `AutoPlace=true` |
| `SmoothSpeed` | `420` | Макс. скорость поворота в режиме `Smooth`, °/с (`60–1080`); видна при `Rotate=Smooth` |
| `SmoothAccel` | `2600` | Макс. ускорение поворота в режиме `Smooth`, °/с² (`300–9000`); видна при `Rotate=Smooth` |
| `SmoothBrake` | `12` | Коэффициент торможения поворота в режиме `Smooth`, 1/с (`2–30`); видна при `Rotate=Smooth` |

### `AutoSwitch`

Доступные значения:

- `Normal` — выбрать строительный блок в hotbar обычным способом и оставить его выбранным;
- `Silent` — временно отправить серверу выбранную ячейку, установить блок и вернуть исходную ячейку;
- `Inventory` — временно обменять строительный блок из основной inventory с текущей ячейкой,
  установить блок и вернуть содержимое обратно;
- `None` — не искать другую ячейку: используется только уже выбранный строительный блок
  в main hand или block item в offhand.

Если в основной inventory нет блока, `Inventory` использует доступный блок из hotbar.

### `Rotate`

Доступные значения:

- `Normal` — обычная мгновенная ротация к найденной грани;
- `Smooth` — настоящая плавная ротация: временной контроллер с трапецеидальным
  профилем скорости (разгон, ограничение скорости, пропорциональное торможение
  у цели без перелёта и колебаний). Настройки: `SmoothSpeed` (макс. скорость,
  °/с), `SmoothAccel` (ускорение, °/с²), `SmoothBrake` (коэффициент торможения,
  1/с — больше значение, позже и резче торможение);
- `Linear` — равномерное перемещение к цели фиксированным угловым шагом;
- `None` — ротация не меняется. Для установки требуется вручную навести crosshair
  на грань блока-опоры, после чего `AutoPlace` выполнит взаимодействие.

### `ClientLock`

- `true` — управляемая ротация отображается на экране игрока (прежнее поведение);
- `false` — silent-ротация тем же механизмом, что у `AttackAura`
  (`RotationManager.update` с `visible=false`): камера полностью свободна от
  первого и от третьего лица и модулем не трогается, а персонаж от третьего
  лица сам смотрит на ближайшую ячейку моста. Голова наводится на следующую
  ячейку моста заранее (пред-прицел), поэтому блок ставится в тот же тик,
  когда игрок на неё наступает.

## Поведение `AutoPlace`

При включённом `AutoPlace` модуль ищет заменяемый блок непосредственно под игроком,
находит видимую грань соседнего твёрдого блока-опоры в пределах interaction reach и
использует выбранный строительный блок для установки. Интервал ограничивается
настройкой `CPS`; одновременно выполняется не более одной попытки за интервал.

### Строительство по одной оси

Пока игрок движется, мост строится только по доминирующей оси движения (`X` или
`Z`, с гистерезисом против случайных переключений на диагоналях):

- опора ищется только позади игрока вдоль этой оси (затем — блок под целью),
  боковые грани не используются;
- yaw ротации фиксируется на кардинальном направлении против движения,
  от точки установки зависит только pitch — камера не дёргается за каждой гранью;
- ввод движения пересчитывается относительно управляемой ротации, поэтому
  разворот головы не меняет мировую траекторию и мост остаётся ровным.

Ось и направление моста определяются по фактической скорости движения
(траектории тела), а не по камере, и фиксируются, пока игрок движется.
Поэтому при `ClientLock=false` повороты камеры вообще не влияют на модуль:
можно свободно смотреть и идти в любую сторону — серверная ротация модуля
останется направленной к мосту и продолжит ставить блоки. Клавиши движения
нужны только для первого шага из неподвижного состояния. При этом спринт
игнорируется: серверная ротация развёрнута назад, и спринт против неё
создавал бы только невалидные спринт-пакеты.

Если игрок стоит на месте, используется прежний свободный поиск лучшей видимой
грани.

### `LockY`

При включённом `LockY` высота строительства фиксируется на уровне `Y`, где
мост был начат: прыжки больше не уводят мост вверх, блоки ставятся только по
`X`/`Z`. Уровень переустанавливается, когда игрок стоит на твёрдой земле на
другой высоте (спуск по склону, начало нового моста).

### `Diagonal`

При включённом `Diagonal` мост может идти не только по `X` или `Z`, но и по
диагонали (`XZ`/`ZX`), если движение действительно диагональное. Yaw ротации
при этом фиксируется на диагональном направлении против движения, а опора
ищется по обеим граням шага: диагональный мост физически строится
чередующимися шагами по `X` и `Z`, и предыдущий блок всегда оказывается
гранью-опорой следующего.

`Eagle` продолжает работать независимо от `AutoPlace`: если под игроком воздух,
модуль удерживает `options.keyShift`, чтобы игрок не сошёл с края. При отключении
`Scaffold` Shift отпускается, а активная ротация модуля прекращается.
