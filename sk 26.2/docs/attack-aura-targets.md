# Attack Aura: проверка профилей целей

В настройках **Attack Aura → Профиль целей** доступны `Обычный сервер` (по умолчанию) и `BedWars`. Видимый список принадлежит только выбранному профилю. Режим ротации и сортировка меняются отдельно.

Для проверки на Windows с JDK 25 из каталога `sk 26.2` выполните `./gradlew.bat build`, затем `./gradlew.bat runClient`. В локальном мире или на своём тестовом сервере поставьте цели в пределах дальности атаки. Для проверок живых целей на земле отключите «Только криты», чтобы не спутать выбор цели с ожиданием подходящего удара.

| Сценарий | Ожидаемое поведение |
|---|---|
| `BedWars`, включены «Игроки» и «Игнорировать команду» | Два одинаковых непустых шлема исключают цель. Другой предмет, другой цвет или другой компонент шлема — не совпадение. Две пустые головы не делают игроков союзниками. |
| Выбранный противник надевает такой же шлем, как у вас, или попадает в список друзей | При соответствующем включённом исключении аура больше не должна бить эту цель. Снятие одного исключения не отменяет остальные. |
| `BedWars`, включены только «Снаряды» из типов целей | Чужой отбиваемый огненный шар может стать целью, собственный снаряд и неуязвимая для удара стрела — нет. HUD для живых целей не пытается показать здоровье снаряда. |
| `BedWars`, включены «Монстры» | Враждебный моб подходит. Житель/торговец подходит только при снятом «Игнорировать жителей». При выключенных «Монстрах» жители целью не становятся. |
| `Обычный сервер`, по очереди оставить «Игроки», «Животные», «Монстры», «Стойки» | Выбирается только включённая категория. Стойка-маркер и снаряд не попадают в обычные цели. |
| «Игнорировать голых», «Игнорировать невидимок», «Игнорировать друзей», «Игнорировать креатив», «Игнорировать ботов» | Проверить каждое исключение отдельно. Голый игрок — с четырьмя пустыми слотами брони. Для друга используется список SkyCore, для бота — результат включённого Anti Bot. Зрители исключены независимо от креатива. |
| Выключить все типы целей; повторить на элитрах с Elytra Target | Цели нет, даже если все «Игнорировать…» тоже выключены. В полёте применяются те же исключения, что и на земле. |
| Выбрать разные опции двух профилей, сменить профиль, сохранить и загрузить конфиг | Сохраняются активный профиль и оба независимых списка. Старый список `Targets` импортируется в настройки обычного сервера. |
