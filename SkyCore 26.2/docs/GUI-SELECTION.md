# Выбор GUI: чем закончился обзор клиентов в папке

Дата: 2026-10-27. Задача: посмотреть ClickGUI всех клиентов в репозитории, выбрать лучший
и перенести его схему в SkyCore 26.2.

Связанный документ: `docs/GUI-AUDIT-ARCANIC-VS-SKYCORE.md` — предыдущее сравнение
Arcanic ↔ SkyCore, из которого видно, почему схема «карточки + всплывающее окно»
(`gui/menu/MenuScreen`) больше не устраивает.

---

## 0. Итог

Выбран **Phobia** (`system/screensystem/clickgui/*`) — однопанельное рабочее
пространство: сайдбар категорий, шапка с поиском, сетка карточек модулей и панель
настроек выбранного модуля справа. Схема перенесена как **новое меню Workspace**
(`net.skycore.client.gui.workspace`), при этом внешний вид взят не из Phobia, а из
собственной палитры и примитивов SkyCore (`MenuDraw`, `MenuPalette`, `MenuPrefs`).

**Workspace — основное меню.** Бинд `ClickGUI` открывает его, а старые экраны
(`Swerve` — порт Arcanic, `Skycore` — исходное меню `RenderGuiHelper`) доступны только
по явному выбору в настройке `Interface`, которая живёт в карточке модуля `ClickGUI`
уже внутри Workspace.

Настройка переименована с `Menu style` на `Interface` намеренно: конфиг хранит режим по
имени настройки, и сохранённое ранее значение `Swerve`/`Skycore` продолжало открывать
старый экран — а в нём клик по списку режимов проваливается в модуль позади, так что
переключиться на Workspace было невозможно. Старый ключ больше не читается, поэтому
первый запуск новой сборки всегда даёт Workspace. Если Workspace не удалось построить,
`SkycoreClient` пишет ошибку в лог и открывает старый экран — без интерфейса клиент
не остаётся.

Отдельно проверялся YouGame (`skycore`, ClickGUI-темы): доступные описания — те же
dropdown/panel-схемы, ни одной реализации лучше Phobia в сниппетах не нашлось, тела
тем закрыты авторизацией. Проверка интернета: `yougame.biz` не открылся (TLS), работали
только поисковые сниппеты — это ограничение отмечено, а не выдано за проверку.

## 2. Почему Phobia

1. **Одно окно вместо попапов.** Девять типов настроек SkyCore (bool, число, режим,
   мультивыбор, строка, цвет, бинд, действие) в панели справа читаются списком, а в
   попапе Arcanic требуют прокрутки внутри прокрутки.
2. **Поиск в шапке.** У Phobia он ищет по всем категориям сразу; это единственная
   схема, где поиск не ломает расположение карточек.
3. **Сайдбар — единственный источник навигации.** Не нужно держать состояние
   «какая панель открыта» и синхронизировать его с попапами.
4. **Геометрия предсказуема.** Фиксированные зоны (сайдбар / шапка / список / панель)
   считаются формулой, а не измерением текста в кадре, поэтому раскладку можно
   проверить без запуска игры.
5. Что **не** взято: собственный атлас, шейдеры и пофреймовые `HashMap<String,…>`.
   В SkyCore это уже признано неприемлемым (см. п. 8 аудита Arcanic).

## 3. Что сделано

Новый пакет `src/main/java/net/skycore/client/gui/workspace/`:

| Файл | Роль |
|---|---|
| `WorkspaceLayout.java` | чистая математика раскладки, без Minecraft: `u = min(H/1080, W/1060) · scale · 0.86`, окно 1000×660u, сайдбар 196u, шапка 40u, панель ≤ 312u, карточка 52u, 1–2 колонки |
| `WorkspaceTheme.java` | токены цвета из `MenuPalette` (20 палитр, светлая тема, плавный переход), свои оттенки только там, где в палитре нет нужного |
| `WorkspaceDraw.java` | составные детали: окно с blur-подложкой, сайдбар, разделитель, тумблер, чип, ключ-чип, скроллбар, иконки |
| `WorkspaceSettings.java` | строки настроек девяти типов, высоты по типу, хит-области через `Sink`, анимации по int-ключам |
| `WorkspaceColorPicker.java` | SV-квадрат, полоса тона, альфа, HEX, 12 готовых цветов |
| `WorkspaceScreen.java` | сам экран: сайдбар с поиском и палитрой, карточки, панель настроек, поповеры, ввод, сохранение |

Правила кадра соблюдены: ни одной лямбды, конкатенации строк или `new` в отрисовке;
хит-области — массивы `float`/`int`; анимации — `MenuAnim` с целочисленными ключами
(карточки `3000 + index·4`, строки настроек `9000 + row·4`); строки за пределами
видимой части панели не рисуются.

## 4. Управление

| Действие | Что делает |
|---|---|
| ЛКМ по карточке | выбрать модуль, настройки справа |
| ЛКМ по тумблеру на карточке / в панели | включить/выключить модуль |
| ПКМ по карточке | включить/выключить без выбора |
| СКМ по карточке или чипу клавиши | назначить клавишу (`Esc`/ПКМ — сбросить) |
| ЛКМ по категории | переключить раздел, сбросить поиск |
| `Ctrl+F` | фокус в поиск |
| `Esc` | закрыть поповер, затем поиск, затем меню |
| Колесо над списком/панелью | прокрутка (плавная) |
| Кнопка «Палитра» в сайдбаре | 20 палитр, размытие, градиенты, размер меню |

Настройки цвета и строки применяются на месте; запись конфига — один раз при закрытии
(`ConfigManager.save()`), оформление — `MenuPrefs.save()`.

## 5. Чего в Workspace пока нет

Осознанно не переносилось, чтобы не обещать несуществующего:

- конфиги, косметика, автобай и прочие разделы старого меню `Skycore` — они остаются
  в своём экране, который никуда не делся;
- пипетка по скриншоту и RGB-режим ввода цвета (требуют чтения кадра в 26.2 —
  отдельная проверка);
- редактор HUD — у SkyCore его нет ни в одном меню.
