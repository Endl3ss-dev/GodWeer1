# AIACDetector — определение античита и подбор обхода

## Что это

`AntiCheatDetector` — фоновая функция клиента. Она включена всегда (инициализируется в
`CommandManager`) и **ничего не отправляет на сервер**: только слушает входящие пакеты и
накапливает признаки. На основе этих признаков строится рейтинг античитов, а `AutoBypass`
выставляет соответствующий профиль Speedv3.

## Из чего складывается определение

| Источник | Что даёт | Вес |
|---|---|---|
| `minecraft:brand` (`BrandPayload`) | Paper / Purpur / Velocity / Fabric — сужает список | 1.5 |
| Каналы плагинов (`DiscardedPayload.id`, `payload.type().id`) | `matrix:main`, `vulcan:sync`, `intave:…` — самый точный признак | 3.0 на канал |
| Чат (`ClientboundSystemChatPacket.content`) | вывод `/plugins`, сообщения о флагах и киках | 2.0 |
| Таб-лист (`ClientboundPlayerInfoUpdatePacket.Entry.displayName`) | имена ботов/служебных записей | 2.0 |
| Поведение | сеты (`ClientboundPlayerPositionPacket`), частота ping/keepalive | в отчёт |

Ключевые слова каждого семейства лежат в `AcFamily`: grim, matrix, vulcan, intave, verus,
spartan, nocheatplus, aac, karhu, polar, themis, negativity, fiona, kauri, hylex, aloha,
errata, watchdog.

## Команды

```
.ac                      краткая сводка (топ-догадка, каналы, сеты)
.ac report               полный отчёт в чат
.ac speed                телеметрия спидов по режимам
.ac save                 полный отчёт в файл run/skycore-ac-report.txt + консоль
.ac auto                 применить профиль Speedv3 под найденный античит
.ac apply <family>       применить профиль вручную (grim, matrix, vulcan, ...)
.ac setup                настройки Speedv3 / Speed / Speedv2 + проверка (что режет скорость)
.ac default              сбросить Speedv3 к значениям по умолчанию
.ac reset                обнулить накопленные данные
```

## Телеметрия спидов

`SpeedTelemetry` считает по каждому тику горизонтальное смещение и группирует данные по
активному модулю/режиму:

```
Speed > Nuclear [Matrix] | тиков 760 | в движении 13.10 bps (тиков 300) | max 18.9 bps | воздух 41% | сеты 4 | флаги 1 | x2.15 к базлайну
-                       | тиков 600 | в движении 6.05 bps (тиков 420)  | max 6.2 bps  | воздух 8%  | сеты 0 | флаги 0
ИТОГО в движении 9.02 bps | сеты 4 | флаги 1 | скачков 0 | смен режима 1
базлайн без модуля: 6.05 bps (ванильный спринт ~5.6-6.1)
```

Почему считаем «в движении»: пока стоишь, средняя по всем тикам падает к нулю и режимы
сравнивать нельзя. Смотрим на `в движении` и множитель `x...` к базлайну (скорость без
модуля, измеряется автоматически, когда Speed выключен).

Скачки больше 1.2 блока за тик (сет, телепорт) в средние не попадают — они считаются
отдельным счётчиком `скачков`.

## Методика: как вообще делается обход

1. **Понять модель сервера.** Любой современный AC (Grim, Karhu, Negativity) — это
   предсказание: сервер сам считает, где ты должен быть, и сравнивает с твоей позицией.
   Обход — не «ускорить клиент», а **попасть внутрь конверта предсказания**.
2. **Знать свою физику точно.** Атрибуты движения (бафы, замедление, крауч, использование
   предмета, спринт), friction блока под ногами, `tickFriction`, множители прыжка. Ошибка в
   friction на 0.02 = постоянный флаг на льду.
3. **В воздухе скорость добавляется, а не перезаписывается.** Сервер считает
   `motion * 0.91`, поэтому клиент обязан сначала взять предсказанный перенос, потом добавить
   свой импульс — иначе расхождение копится.
4. **Конверт.** У предсказания есть допуск (offset). Выход за `softCap` — плавное сжатие,
   за `hardCap` — сет. `Strictness` в Speedv3 — это и есть конверт.
5. **Разнообразие.** Повторяемые значения ловятся статистикой (Verus, Hylex), поэтому
   микро-джиттер и yaw-демпфирование.
6. **Тайминги.** Таймер > 1.05 ловят Vulcan/Watchdog; на Grim таймер не трогаем вообще,
   а компенсируем задержкой транзакций.
7. **Проверка.** Один режим → прыжки 20–30 секунд → `.ac speed` → сменил режим → снова.
   Смотришь `avg` и `сеты`. Сетов нет и avg выше — обход рабочий.

## Рабочий цикл

```
.ac reset
(включить режим, прыгать 20-30 сек, при флагах смотреть чат)
.ac speed          → сравнить avg/сеты
.ac save           → файл run/skycore-ac-report.txt, кинуть его целиком
```
