# AttackAura: режим 1.8 (пачки ударов)

Перенос режима **`1.8 NoDelay`** из SkyCore 26.2 в Pouch (Minecraft 1.21.4).
В Pouch он называется просто **`1.8`**.

В `AttackAura` добавлены три настройки после `Коррекция`. Правила выбора цели, дистанция,
проверка луча, профиль таргетов, сброс спринта, «Отжимать щит» и «Ломать щит»
не менялись — новый режим подменяет **только часы ударов**.

| Настройка | Что делает |
|---|---|
| `Режим кликов` | `1.9` (по умолчанию) — прежний темп Pouch: ванильная перезарядка оружия `getAttackCooldownProgress` вместе с прежним троттлингом 467 мс. `1.8` — перезарядка оружия и окно крита не проверяются, удары уходят пачками. Старый конфиг без новых ключей открывается в `1.9` и работает как раньше. |
| `Ударов за тик` | Сколько ударов уходит **одним пакетом** за игровой тик. 1–50, по умолчанию 5. Донор (MotherHack) разрешает до 500 — здесь потолок ниже, потому что такие пачки кикают сервер и подвешивают клиент. |
| `Анти-кик` | По умолчанию включён: разносит пачки по времени вместо удара каждый тик. |
| `Задержка анти-кика` | 10–200 мс, шаг 10, по умолчанию 50. То есть примерно одна пачка на 2–3 тика. Виден только при включённом `Анти-кик`. |

## Как это работает

* В режиме `1.8` ванильный кулдаун оружия и окно крита не проверяются вовсе: пачка из
  `Ударов за тик` ударов отправляется одним пакетом в одном тике.
* Пачка **никогда не чаще одного раза за игровой тик**, даже если логика вызвана и из тика,
  и из подшага кадра. Окно анти-кика считается в наносекундах.
* Дистанция, луч, профиль цели и сброс спринта проверяются на каждой попытке — режим меняет
  только темп ударов, но не отбор цели.
* Состояние сбрасывается при выключении модуля, включении, потере цели и загрузке профиля.
  В режиме `1.9` пачки не используются совсем, а поле прежнего троттлинга ведёт себя
  в точности как до переноса.

## Проверка

Сборка и запуск — из каталога `Pouch` (`gradlew.bat build`, затем `runClient`; JDK 21+).

1. По умолчанию (режим `1.9`) поведение ауры не должно меняться.
2. `1.8`, `Ударов за тик = 1`, `Анти-кик` выключен: удары примерно 20 раз в секунду, без пачек.
3. `1.8`, `Ударов за тик = 5`, `Анти-кик = 50 мс`: пачки примерно раз в 2–3 тика, в сумме
   около 100 ударов в секунду.
4. Ударьте в щит: «Ломать щит» срабатывает до пачки, а не N раз подряд.
5. Уберите цель из профиля или выйдите из радиуса — атак нет ни в одном режиме.
6. Сохраните профиль в режиме `1.8`, загрузите заново: режим, число ударов и анти-кик восстанавливаются.

Источник: `sk 26.2/src/main/java/net/skycore/client/module/combat/AuraBurst.java`
(в SkyCore это `AuraClicks.NO_DELAY`), который в свою очередь опирался на MotherHack
`Aura#attack` — `attacksPerTick`, `antiKick`, `antiKickDelay`. Зависимостей от этих
проектов не добавлено.
